# Кинотека для Samsung TV

Оболочка приложения для телевизоров Samsung (Tizen): значок «Кинотеки» на главном экране телевизора,
внутри открывается личная полка фильмов и сериалов (вход по паролю). Пульт работает как пульт: стрелки, ОК, «Назад».

Установка — через [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller): «установить приложение из GitHub» → `Maks-nerd/kinoteka-tv`.
